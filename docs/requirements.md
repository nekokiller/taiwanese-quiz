# 台灣台語字音字形測驗練習網頁 — 需求文件

最後更新：2026-10-20

## 1. 目標

提供國小學生練習「臺灣台語字音字形」語文競賽的讀音。系統從題庫隨機出題，學生唸出台語讀音後，系統把錄音與標準語音檔比對並給分；學生可以播放標準發音來對照學習。

## 2. 題庫與音檔

### 2.1 來源

| 項目 | 來源 | 位置 |
|---|---|---|
| 試題 | 信義國小 115 學年度語文競賽—臺灣台語字音字形（題目引自 113 年全國語文競賽【國小組】），共 6 頁 | [reference/](reference/)（6 張照片） |
| 試卷抄錄 | 照片逐題抄錄，200 題，是題目的依據 | `data/exam.csv` |
| 音檔 | 教育部《臺灣台語常用詞辭典》<https://sutian.moe.edu.tw/> 原始 MP3，未剪輯 | `taiwanese-pronunciation-200-mp3/mp3/`（307 個） |
| 音檔對照表 | 每段錄音對應的題號、詞目、臺羅、原始網址 | `taiwanese-pronunciation-200-mp3/音檔對照表.csv` |
| 題庫 | 由對照表產生，一題一筆 | `data/questions.json`（以 `scripts/build_questions.py` 產生） |

### 2.2 範圍

- **字音** 第 1–100 題：題目給漢字詞，考「」內的字的臺羅讀音。
- **字形** 第 1–100 題：試卷原本是看臺羅寫漢字。本網頁改成「看漢字詞，唸出讀音」，和字音題一樣練習。試卷上只有臺羅，所以漢字詞要依照教育部詞目還原。
- 試卷共 200 題，每題都有錄音，都可以出題。

### 2.3 題庫欄位（`data/questions.json`）

| 欄位 | 說明 | 範例 |
|---|---|---|
| `id` | A＝字音、B＝字形，後面接三位數題號 | `A007` |
| `section`, `no` | 部分、題號 | `字音`, `7` |
| `paper` | 試卷原文（字形題是臺羅） | `「鋼」琴`、`tshiū-「ńg」` |
| `prompt` | 題面漢字詞（字形題還原前是 `null`） | `鋼琴` |
| `promptNote` | 題面附註：字形題沒有整詞錄音時，附上試卷臺羅（會洩漏答案，作答後才顯示） | `tè-ám` |
| `target` | 考的字，即「」內的字 | `鋼` |
| `readings` | 試卷上的單字讀音（多種腔調） | `["kǹg"]` |
| `uncertain` | 照片上的字還不確定時的說明 | — |
| `speak` | 使用者要唸的詞，也就是標準音檔的內容 | `鋼琴` |
| `speakRomanization` | 要唸的詞的臺羅 | `["kǹg-khîm"]` |
| `reference` | 評分用的標準音檔，沒有錄音時是 `null`（這題不出題） | `A007_2_鋼琴.mp3` |
| `audio[]` | 這題所有的錄音（整詞、單字本調、同字參考詞） | — |
| `gaps` | 缺少的錄音：`noAudio`（完全沒有）、`wordAudio`（整詞）、`charAudio`（單字）、`readings`（沒有錄音的腔調） | — |

## 3. 功能需求

### 3.1 測驗設定（測驗開始前）

0. 選擇**模式**：「測驗」（本節以下各項）或「練習」（見 3.7）。
1. 選擇**題目範圍**：
   - 選部分：字音、字形，或兩者都選。
   - 在每個部分裡選題號區間，例如字音 1–30。
   - 只會出有錄音的題目（`reference` 不是 `null`）。範圍裡有沒錄音的題目時，要顯示「此範圍有 n 題尚無錄音」。
2. 選擇**題數**：可以選常用題數（10、20、30），也可以自己輸入。上限是範圍內的題目數，超過時提示並自動調整為上限。
3. 按下「開始測驗」。

### 3.2 出題

- 從選定範圍隨機抽題，同一輪不重複。
- 顯示「第 n / N 題」的進度。

### 3.3 題目畫面

- 顯示題面詞，目標字用「」標示並加強，例如 `「鋼」琴`。題面中目標字出現多次時，標示第一個，例如 `花「彔」彔`。
- 顯示「請唸：`speak`」。
  - **使用者要唸整個詞**，不是只唸單字，因為一半以上的題目只有整詞錄音，而整詞中的字可能會變調。
  - 下列 10 題沒有可用的題面整詞錄音，改唸其他內容，畫面要特別註明：

    | 題目 | 題面 | 改唸 |
    |---|---|---|
    | 字音 2 | 蘭嶼 | 島嶼（同字參考詞） |
    | 字音 21 | 明呼明唱 | 唱 |
    | 字音 33 | 亥時 | 亥 |
    | 字音 48 | 食甲真飫 | 飫 |
    | 字音 57 | 熁燒 | 熁 |
    | 字音 62 | 𫝻手機仔 | 𫝻 |
    | 字音 95 | 四界遹 | 遹 |
    | 字形 21 | 致重 | 重 |
    | 字形 74 | 擔頭 | 擔（整詞錄音是 tànn-thâu，試卷要的是 tann） |
    | 字形 82 | 一簇人 | 簇 |

    另外，字形 3、5、22、32、42、48、49、65、96、100 題只有單字錄音，所以題面就只顯示單字，讓使用者唸單字。
- 作答前不顯示臺羅（包括 `promptNote`），避免直接看答案。

### 3.4 錄音與評分

1. **按住**錄音按鈕開始錄音，**放開**就停止。
   - 同時支援滑鼠和觸控（Pointer Events），按住時要有明顯的錄音中提示。
   - 錄音太短（例如不到 0.3 秒）或沒有聲音時，提示重錄，不評分。
2. 放開後，系統把錄音和 `reference` 音檔比對，計算相似度。
3. 顯示 **0–100 分**，並同時顯示正確的臺羅（`speakRomanization`、`readings`）。
4. 試卷上的腔調如果沒有錄音（`gaps.readings` 不是空的），要提示「另有其他腔調讀法：…，與標準音不同不代表唸錯」。
5. 可以重錄，分數以最後一次為準（或最高分，待確認）。

### 3.5 播放標準發音

- 「發音」按鈕：播放 `reference` 音檔，可以重複播放。
- 這題如果另有單字本調錄音，加一個「單字」按鈕來播放。
- 錄音中不能播放，播放中也不能錄音。

### 3.6 測驗結束

- 顯示總平均分數和每一題的分數。
- 可以「只重練低分題」，或重新設定再測一次。

### 3.7 練習模式（2026-10-20 新增）

給還不熟的題目先聽、先背，不錄音、不評分，也不需要麥克風權限。

1. 設定時只選題目範圍，不選題數。範圍內的題目全部列入，依題號順序排列（字音在前、字形在後）。
2. 每一題顯示：
   - 題面（考字標「」）
   - 讀音：標準音的臺羅、試卷讀音，字形題另外顯示試卷題目
   - 其他腔調提示（同 3.4）
3. 按鈕：
   - 「標準發音」，有單字錄音時另有「單字」按鈕
   - 「上一題」「下一題」，第一題和最後一題時分別停用
   - 「隱藏讀音／顯示讀音」：自我檢查用，換題後維持同樣設定
   - 「結束練習」：回到設定畫面
4. 桌機可以用鍵盤左右鍵換題。

## 4. 比對方法

採**純前端聲學比對**，不需要後端，可以部署成靜態網站：

1. 用 Web Audio API 把錄音和標準音解碼成相同取樣率，並切除前後靜音。
2. 抽取 MFCC 特徵，用 DTW（動態時間校正）計算音色和音段的相似度。
3. 抽取基頻（音高）曲線，正規化後用 DTW 比對，評估聲調。台語聲調會區分字義，所以必須比對聲調。
4. 把兩個分數加權合成 0–100 分。權重和分數門檻要用實際錄音調整。

限制：分數會受音色、性別、年齡和環境噪音影響，只能當練習參考。未來如果需要更準確的評分，或想指出錯在聲母、韻母或聲調，可以改用台語語音辨識轉成臺羅再比對，但這需要後端或外部服務。

## 5. 需搜尋補齊的語音檔

目前的音檔不能涵蓋每一題的每一種讀法，需要另外搜尋補齊。逐題的盤點結果見 [audio-inventory.md](audio-inventory.md)。

**盤點方式**：先把試卷 6 頁照片逐題抄錄到 `data/exam.csv`（題面、考字、讀音），再和音檔對照表、錄音的辭典臺羅交叉比對（`build_questions.py` 每次執行都會自動檢查）。

**結果**（音檔：`taiwanese-pronunciation-200-mp3`，307 段錄音）：

- 試卷 200 題**每題都有評分用的標準音**。抄錄和對照表的考字、讀音完全一致。
- 照片上原本看不清楚的 5 個字，已經依照教育部詞目確認：15 沬、22 𢼌、31 倏、40 𧉟、58 䢢。字形 3 題我原本抄成「滯」，經對照表比對後，重看照片確認是「渧」。
- 字形題的整句臺羅和整詞錄音一致，只有第 74 題的錄音聲調不同（見 5.1）。
- 對照表字形 3 題附註的臺羅寫成 tè-àm，試卷是 tè-ám。題庫已改用試卷的寫法。

以下依優先順序列出還缺的音檔。這些都不影響出題，補到之後可以讓練習更貼近試卷。

### 5.1 題面整詞錄音（20 題）

這些題目沒有可用的題面整詞錄音，現在只能改唸單字或參考詞（見 3.3）。補到之後，就可以讓使用者照試卷題面唸。

### 5.4 搜尋與收錄規則

1. **來源優先順序**：
   1. 教育部《臺灣台語常用詞辭典》的詞條和例句音檔
   2. 其他教育部或官方台語資源
   3. 真人錄音（例如請老師錄製）
   - 合成語音（TTS）只能當最後手段，畫面上要標示「合成語音」。
2. 每段新音檔都要記錄原始網址、詞目和臺羅，加進 `音檔對照表.csv`，檔名沿用 `{A|B}{題號}_{序號}_{詞目}.mp3` 的格式。
3. **不剪輯、不修改**原始音檔，以符合授權（見第 6 節）。
4. 更新 CSV 之後執行 `python scripts/build_questions.py`，重新產生題庫，`gaps` 欄位會自動更新。

## 6. 非功能需求

- **平台**：支援手機和平板瀏覽器（Chrome、Safari），也支援桌機。版面以手機直式為主。
- **部署**：靜態網站，例如 GitHub Pages。瀏覽器使用麥克風必須在 **HTTPS 或 localhost** 下。
- **麥克風權限**：第一次錄音時要求權限，被拒絕時要顯示如何開啟權限的說明。
- **相容性**：iOS Safari 的錄音格式和自動播放限制要另外測試。
- **罕用字顯示**：題庫有 8 個字在擴充 A 區以後：𦜆、𣻸、𫝻、𩸶、𢼌、𧉟、䢢、𤺪。
  - Windows 可以正常顯示。
  - Google Noto 字型只收錄其中的 𣻸，所以 Android 和 iOS 可能顯示成方框。
  - 需要隨網頁附上收錄這些字的字型子集（待處理）。
- **授權標示**：頁面上要註明音檔來源是教育部《臺灣台語常用詞辭典》並附上連結。據了解授權是 CC BY-ND 3.0 TW，需要到網站確認。
- **隱私**：錄音只在瀏覽器裡分析，不上傳，也不保存。
